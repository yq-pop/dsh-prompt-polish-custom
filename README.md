# dsh-prompt-polish-custom

针对 **DeepSeek Harness 0.2.0-rc.2** 的提示词优化定制版本。
本仓库导出当前实际安装的 `dsh-prompt-polish@0.3.2-local.dsh020rc2.6`，不是仅修改兼容版本声明的原版。

## 功能

- 六种优化策略：默认、压缩精简、结构化、创意扩展、翻译并优化、代码请求。
- 选择独立优化模型，或跟随 DSH 全局默认；实际请求使用所选路由。失效选择报错，不偷偷换模型。
- 优化展示形式：默认弹窗展示，或替换输入框内容；绿色“已优化”支持安全撤回原稿，再次点击重新优化。
- 图像上下文：默认关闭，或结合当前输入框完整图片。没有图片时自动使用纯文本请求，不报无图错误、不修改保存的偏好。已移除选框/裁剪模式。
- 可结合聊天上下文、目标、任务和工具摘要；图片仅用于理解原稿，不应将优化器内部任务包装当成用户需求。
- 保留 L1（浏览器）、L2（页面内存）、L3（工作区设置）保存链路，旧配置兼容迁移。
- 手动编辑、附件变动、切换会话或取消后的迟到结果不会直接覆盖草稿；不会自动发送消息。

## 部署

详见 [DEPLOYMENT.md](DEPLOYMENT.md)。插件包名仍为 `dsh-prompt-polish`，仓库名是 `dsh-prompt-polish-custom`；不要把原版与本定制版同时挂载。

## 开发与测试

本实现直接维护 `lib/` 中的 JavaScript。`build` 是入口语法检查，不是编译器。

```sh
pnpm install --ignore-scripts
pnpm run build
pnpm test
```

Node 使用 DSH 所支持的现代版本（推荐 Node 24），pnpm 请使用环境中可用的版本。`.npmrc` 禁止自动安装运行时 peer 和第三方安装脚本；运行时由 DSH 提供。测试仅需要本项目的 zod 依赖。

## 代码结构

- `lib/index.js`：Host 服务、选路、图片验证与模型调用、取消、工作区设置。
- `lib/shared.js`：优化系统指令与纯逻辑。
- `lib/client.js`：设置界面、输入栏按钮、预览/替换/撤回、图片编码。
- `lib/typert.host.js`：Host RPC 清单；客户端对应清单维护在 client 中。
- `cordis.patch.yml`：单一稳定插件入口。
- `test/`：模型路由、行为、图片和任务边界回归。

## 验证范围与限制

历史本地回归覆盖模型选路、取消、安全替换、无图回退及合法图片校验。已做过真实模型及图像请求验收，但单元测试不是对任意模型响应质量的保证。草稿相关上下文过多时仍可能过度扩写；模型生成结果应由用户检查。此仓库不宣称已经解决所有指令遵循问题。

整体图片会发送到所选模型的提供商，非完全本地识别。模型不支持视觉时明确报错；不自动切换模型或 OCR。DSH 后续版本未验证，不建议通过版本豁免强行运行。
